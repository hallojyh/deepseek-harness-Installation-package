DeepSeek Harness 安装版使用说明（Windows）
============================================

本软件为 DeepSeek Harness 封装版 v0.1.0，基于开源项目
deepseek-ai/deepseek-harness（上游 0.1.0-rc.6，MIT 协议），内置 Node.js
运行时、pnpm 与全部依赖，开箱即用，无需自行安装任何环境。
GitHub: https://github.com/deepseek-ai/deepseek-harness

一、安装
  双击安装包 DeepSeek-Harness-Setup.exe，按向导提示一步步操作即可：
    1) 欢迎页 -> 点击“下一步”；
    2) 阅读“使用许可与免责声明”，选择“我接受该许可协议的条款”后
       “下一步”按钮才会变为可用（不同意则无法继续安装）；
    3) 选择安装位置（默认 %LOCALAPPDATA%\Programs\DeepSeek Harness），
       可点“浏览”更换，无需管理员权限；
    4) “安装” -> 等待进度完成；
    4) 完成页可勾选“运行 DeepSeek Harness”，点击“完成”。
  首次启动会自动初始化并打开浏览器进入 Web 界面（http://127.0.0.1:3080，
  端口被占用会自动顺延）。进入界面后在设置中配置模型 API（如 DeepSeek API Key）。

二、卸载
  两种方式任选其一：
    1) 开始菜单 -> DeepSeek Harness -> 卸载 DeepSeek Harness；
    2) Windows 设置 -> 应用 -> 已安装的应用 -> 搜索 DeepSeek Harness -> 卸载。
  说明：卸载只删除程序本体；用户数据（会话记录、配置）保留在 ~/.dsh。
  如需彻底清除，卸载后手动删除 ~/.dsh 目录即可。

三、插件管理（已内置 pnpm，无需单独安装）
  命令行执行：
    "DeepSeek Harness.exe" plugin --profile <名称> add <插件包名>
    例："DeepSeek Harness.exe" plugin --profile my add @deepseek-ai/cordis-plugin-group
  该命令会初始化 profile 并把参数原样转发给内置的 pnpm 完成安装。
  也支持本地插件：plugin --profile my add .\我的插件目录
  （安装后插件会作为 profile 的 bundle 层自动生效）。
  提示1：极少数 git 地址形式的插件需要系统装有 git（与 pnpm 无关）。
  提示2：个别 @deepseek-ai 官方 bundle（如 dsh-web-app、dsh-headless）目前在
  npm 上缺少部分传递依赖（上游仓库发布缺口），添加会报 "not in the npm
  registry"；本地插件与依赖完整的包不受影响。

四、命令行用法（完整 dsh 能力透传）
  "DeepSeek Harness.exe" --help                   查看帮助
  "DeepSeek Harness.exe" --version                查看版本
  "DeepSeek Harness.exe" web --port 8080          指定端口启动 Web
  "DeepSeek Harness.exe" --profile headless "..." 一次性问答模式

五、数据与日志
  - 程序本体：安装目录（默认 %LOCALAPPDATA%\Programs\DeepSeek Harness）
  - 用户数据：~/.dsh （可用环境变量 DSH_HOME 重定向）
  - 服务日志：安装目录\logs\dsh-web.log

六、高级环境变量
  DSH_BASE_PORT=3080   无参数启动时的起始端口
  DSH_NO_BROWSER=1     启动后不自动打开浏览器
  DSH_HOME=<目录>      自定义用户数据目录

七、常见问题
  Q: 开始菜单里找不到卸载入口？
  A: 点“开始”按钮后，在“所有应用”列表里找：
     1) 顶层有一个“卸载 DeepSeek Harness”入口（无需打开文件夹）；
     2) 或进入“DeepSeek Harness”文件夹，里面有“卸载 DeepSeek Harness”；
     3) 也可以直接在开始菜单搜索框输入 DeepSeek，或到
        Windows 设置 -> 应用 -> 已安装的应用 中卸载。
     新装程序若几秒内未显示，稍等片刻或重启资源管理器即可。
  Q: 首次启动时看到“正在启动…”页面？
  A: 首次启动需要初始化本地配置（约 15~30 秒），页面会自动跳转进入软件；
     之后每次启动只需 1~2 秒。
  Q: 首次双击安装包时 SmartScreen 提示“已保护你的电脑”？
  A: 未做商业数字签名属正常现象，点“更多信息 -> 仍要运行”即可。
  Q: 开始菜单图标启动后没看到窗口？
  A: 软件以浏览器为界面，服务在后台运行，会自动打开浏览器页面。

# DeepSeek Harness Windows Package

A third-party Windows installer packaging of the open-source project [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) (upstream 0.1.0-rc.6, MIT License). Works out of the box — no need to install Node.js / npm / pnpm.

- **Package version**: v0.1.0
- **Setup / portable exe / bundle zip**: see [Releases](https://github.com/hallojyh/deepseek-harness-Installation-package/releases)
- Wizard-style installer: custom install path, license agreement page included

## Features

- Wizard install flow: Welcome -> License & Disclaimer (must accept to continue) -> Install location -> Install -> Finish
- Standard uninstall: Start Menu "Uninstall DeepSeek Harness" or Windows Settings -> Apps
- Bundled Node.js runtime + pnpm + all dependencies: `dsh plugin` works out of the box
- Double-click to run: auto-starts the Web GUI and opens your browser (http://127.0.0.1:3080; falls back to the next free port; reuses an existing instance)
- Full CLI passthrough: `DeepSeek Harness.exe --help` / `--version` / `web --port 8080` / `--profile headless "..."`
- Official black-whale favicon icon (rendered as-is from the upstream favicon.svg)

## Quick Start

1. Download `DeepSeek-Harness-Setup.exe` from [Releases](https://github.com/hallojyh/deepseek-harness-Installation-package/releases) and double-click it;
2. Read and accept the license agreement -> choose the install location -> finish;
3. The browser opens automatically. Configure your model API key (e.g. DeepSeek API) in the settings page.

See [使用说明.txt](使用说明.txt) for details (Chinese).

## Plugin Management (bundled pnpm)

```
"DeepSeek Harness.exe" plugin --profile my add <package-name>
"DeepSeek Harness.exe" plugin --profile my add .\path-to-local-plugin
```

Installed plugins are activated automatically as profile bundle layers.

## Complete Source

The repository contains everything needed to rebuild the package:

- `installer/` install script and license terms; `launcher-src/` launcher source and icons; `build-installer.cmd` one-click rebuild script
- **`install-files.tar.gz` (87MB)**: the complete install tree (dsh 0.1.0-rc.6 runtime + dependency tree, bundled pnpm 11, Node.js 24 runtime, and frontend assets) — exactly what the installer writes to the user's machine

Unpack with: `tar.exe -xzf install-files.tar.gz` -> `runtime/`, `app/`, `tools/` (as expected by the build script).

The upstream DeepSeek Harness TypeScript source lives at [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness).

## Rebuild

Requirements: Windows 10/11 x64, Node.js v24+, Inno Setup 7.

```
# 1) Unpack the install tree (if you don't have install-files/ locally)
tar.exe -xzf install-files.tar.gz

# 2) One-click rebuild
build-installer.cmd
```

Outputs: `dist/DeepSeek-Harness-Setup.exe` (installer) + `DeepSeek-Harness.exe` (portable).
The install tree can also be regenerated by pruning the dependency tree of `npm install @deepseek-ai/dsh@0.1.0-rc.6`.
